# Pigeon Notes

A calm, local-first notes editor for Windows, built using **C++20** and **Slint 1.19**.

## Features
- Create, edit, find and delete notes
- Automatic local saves under `%APPDATA%\PigeonNotes\notes`
- Manrope typography, charcoal dark theme and warm soft-light theme
- No accounts, tracking or cloud services required

## Website
[Visit the official site](https://vale-coder.github.io/PigeonNotes/).

The website lives in `website/` and is published by GitHub Pages. To enable deployment, go to **Settings → Pages → Build and deployment → GitHub Actions**.

## Windows app
The C++/Slint source bundle is available in the project package prepared in ChatGPT. The GitHub site is a preview, not a downloadable Windows binary. No signed release has been published yet.
